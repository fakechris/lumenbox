## 2. The day's three lines of work

**Inbound reliability (docs/26).** A question sat unanswered for an hour because
the vendor kept dispatching to a registration killed by a restart while the SDK
logged `socket ready`. Doors now check themselves against the vendor's history
on every connect *and* on the liveness timer; dedup consults the durable ledger,
not memory, because the process a redelivery lands in is the one whose memory is
empty; the sweep's floor is a watermark that never passes an undecided arrival
(OpenClaw's Telegram offset store, read at source); replay is bounded by age and
count with the skips named. Open: the same sweep for DingTalk, and whether
webhook mode should replace the websocket.

**Testing and release (docs/27).** Read OpenClaw and Hermes at source. Building
what they have found three live defects here: the suite had been appending to
the live installation's usage ledger, a test passed only because a key was
exported in this shell, and the packaged CLI had been dead on main for a day
because esbuild bundles code and not the catalog's data files. Added: a hermetic
runner, a network guard, guards that test themselves, an artifact gate in CI
(the built CLI is launched), digest pinning paired with dependabot, a captured
and sanitised Feishu payload corpus with a contract test, and one programmable
fake model replacing thirteen ad-hoc ones. Open: a contract assertion per
adapter, and tiering with a live tier once something needs one.

**External audit (docs/reviews/2026-09-01-runtime-audit.md).** Seven findings,
each reproduced before being touched. Four fixed — caller identity leaking into
unattended turns, scheduled skills able to borrow another agent's permissions,
Recall resurrecting retracted facts, and a same-day skill-cache race. One claim
was partly wrong and is corrected in place. Two remain open and are written up
with what they would cost.
