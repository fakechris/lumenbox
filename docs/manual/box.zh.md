# 沙盒

你的智能体工作的沙盒：怎样得到一个、看着它，以及接管它。

## 这是什么

**沙盒** 是一个 Linux 环境，每个智能体有一个桌面，还有浏览器、文件管理器和 shell。默认的沙盒在你自己机器上的
Docker 里运行；你也可以接入一台在别处运行的沙盒。一个智能体住在一个沙盒里，它的记忆、文件和登录状态都留在那里。

沙盒在运行不等于智能体在工作：沙盒开着的时候，所有智能体都可能空闲。到侧边栏查看：底部显示沙盒的状态，每个
智能体的那一行显示它正在做什么。

## 怎么做

### 在 app 里

- **启动沙盒：** 设置 → 沙盒 → *启动沙盒*。第一次启动要拉取镜像，有几百 MB。
- **更新沙盒：** 设置 → 沙盒页面顶部会提示有可用的镜像更新。按*应用更新*，等智能体完成手头的工作后再更新。
- **添加沙盒：** 按顶部沙盒栏里的 `+ box`，或者用设置 → 沙盒 → *接入*来驱动另一台机器上的沙盒。
- **看着一个智能体：** 选中这个智能体，然后打开右侧的*桌面*标签页。
- **接管：** 在*桌面*标签页上按*接管*，自己使用鼠标和键盘。用完后按*交还*。

### 在聊天里

- `桌面`（或 `desktop`）：智能体回复一个链接，指向它的实时桌面，可以观看或接管。
- `屏幕`（或 `screen`）：桌面此刻的一张截图。不会运行任何一轮。

### 在命令行里

```
agentbox box up            # 启动 box，并等它的桌面就绪
agentbox box status        # 容器状态、端口和健康情况
agentbox box list          # 每个 box，以及哪些 agent 住在里面
agentbox box attach <name> <url> --token-file <file>
agentbox box down          # 停止它；在你重新启动前它一直保持停止
agentbox box shot out.webp # 保存一张桌面截图
```

## 在哪里看结果

- 侧边栏底部：*沙盒在线*或 *沙盒不可用*，以及有几个沙盒开着。
- 沙盒栏：每个沙盒一个标签，已连接时带一个绿点。
- 设置 → 沙盒：每台机器，以及接入的沙盒最近一次的错误。

## 限制

- 智能体的沙盒只选一次。要在另一个沙盒上工作，就在那里新建一个智能体。
- 本地沙盒需要 Docker Desktop 或 OrbStack。第一次启动可能要 10 到 40 分钟。
- 共享的沙盒就是共享的：每个能打开它的人都能看到它的屏幕、读到它的文件。不要在上面登录你自己的账号。
- 如果 LumenBox 之外的东西停掉了本地沙盒，LumenBox 会重新启动它。你用 `agentbox box down` 停掉的沙盒会一直保持停止。
