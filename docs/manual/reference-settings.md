# Reference: the Settings panes

Generated by `scripts/docs-reference.mjs` from `SETTINGS_PANES` (src/web/settings-registry.ts), which the dialog renders its tabs from; `npm test` fails when this page
and the source disagree. Change the source and run `node scripts/docs-reference.mjs --write`.

10 panes. **config** is what the pane edits in `~/.agentbox/config.json`; **API** is the routes behind it. A pane mounted by a script appears when that script has loaded.
