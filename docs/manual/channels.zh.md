# 渠道

人们怎样从飞书或钉钉找到你的 agent，以及谁能进来。

## 这是什么

**渠道**是聊天平台上的一个应用，比如一个飞书应用、一个钉钉应用，它通向你的 box。连接之后，那个聊天里的消息就是发给
agent 的消息，回复也回到同一个聊天里。那里的对话是**群**或私聊。同一个人在所有渠道上都是同一个人，所以在一个渠道里给出的确认，在另一个渠道里也算数。

群里的消息不一定是指令：群规则是*仅在被点名时回复*时，没有点名任何人的消息只作为上下文保留，不会得到回复。到设置 → 渠道查看这条规则。

## 怎么做

### 在 app 里

- **连接渠道：** 设置 → 渠道 → *添加渠道*，选择 `feishu` 或 `dingtalk`，再粘贴从该平台开发者后台拿到的应用凭据。
  凭据就位的渠道会马上连接，不用重启。
- **选择谁来回答：** 每个渠道一行，有一个默认 agent，也就是回答没有点名任何人的消息的那个 agent，还有一条群规则：
  *群：仅在被点名时回复*或*群：回复所有消息*。
- **让人进来：** 设置 → 团队 → *新建邀请码*。一个邀请码只能用一次，有效 15 分钟。在被放进来之前就发过消息的人，会在设置 → 渠道 →
  *等待加入*下面等着；点一下就能让他们进来。
- **让组织里的人进来：** 在组织安装上，设置 → 团队 → 人 → *通讯录* 按部门显示从渠道同步来的名单，默认收起，每个部门带人数。
  *立即同步通讯录* 会重新读取，另外每天自动刷新。展开一个部门可以看到其中的人和各自的状态：*已列出*、*申请加入*、*已激活*、*已离开*。
  选好角色后点某个人旁边的 *激活*，或点 *激活现在名单里的 N 人* 激活整个部门，勾选后可包含子部门。激活后本人立刻成为团队成员：他在这个渠道里发来的消息会被认作本人；限额允许时会为他创建自己的电脑，里面有一个助手（激活整个部门时，电脑每次只启动几台）；本人随时可以用这个渠道登录。激活时创建的电脑就绪后，他的助手会在这个渠道里给他发消息，附上要打开的地址；第一次打开页面时才创建的电脑不发，因为本人已经在页面上了。激活整个部门时会先说明要启动几台电脑、需要集群多少内存，确认之后才开始。之后 *激活后创建的电脑* 按已就绪、正在启动、排队中、失败（附平台给出的原因）计数；*重试* 重新启动失败的电脑，*再通知一次* 给渠道没能送达的人再发一次。
  还没被激活就登录的人会看到“你的加入申请已交给管理员”，并出现在 *申请加入* 下面（这里和设置 → 渠道 都能看到）。
  通讯录里有、但还没被激活的人在这个渠道里私聊，得到同一句话、同一条申请；通讯录里没有的人会被告知不在名单里，不产生申请。
- **连接服务：** 设置 → 渠道 → *连接器* → *连接*，接入一个外部服务（比如 Notion）给 agent 使用。

### 在聊天里

- `bind <code>`（或 `绑定 <码>`）：用邀请码加入。
- `@name <message>`：和你能找到的某一个 agent 对话；其他消息都交给默认 agent，在组织里，私聊交给你自己的 agent。
- `/help`：列出这个聊天能识别的所有命令。
- `看板`、`团队`、`定时`：看板、agent，以及会自己运行的工作。

### 在命令行里

目前还没有渠道命令：渠道在设置 → 渠道里设置，凭据保存在 `~/.agentbox/config.json`。

## 在哪里看结果

- 设置 → 渠道：每个渠道，以及它是否已连接。
- 聊天本身：在飞书群里，回复是你那条消息下面的一个话题。
- 设置 → 团队：每个人和他的角色（观察者、操作者或管理员）。在你的个人安装（你电脑上的桌面 app）里，唯一的人就是你，机主。

## 限制

- 出现在通讯录里不等于能进来；激活部门是一次性的，只针对当时名单里的人：之后加入这个部门的人仍是*已列出*，要等管理员激活。
- 同步后，通讯录不再列出某个靠激活进来的人时，他通过这个渠道的登录失效，显示为*已离开*。他如果还有别的登录方式，那种方式和角色都保留；没有别的方式的人就无法再登录。他的电脑和文件保留，由管理员在“人”的名单里决定。用其他方式进来的人，以及唯一的管理员，不会被同步登出。
- 一次同步会让很多人的登录失效时，不改动任何人：同步到的名单是空的、人数不到上次的一半，或者要离开的人超过 5 个且超过已激活人数的十分之一。这时通讯录一栏会显示“通讯录不再列出 N 位已激活的人；什么都没有改动”和这些人的名字，由管理员点*他们确实离开了*或*名单不对，保持原样*。
- 激活部门时只能选*可以交代工作*或*只能看*。管理员要一个人一个人地设。
- 渠道的 id 只选一次；它会成为它放进来的每个人名字的一部分。显示名称和默认 agent 随时可以改。
- *添加渠道*提供飞书和钉钉。
- 用聊天账号登录网页适用于飞书和钉钉渠道，只在设置了公开地址（`AGENTBOX_PUBLIC_URL`）的安装上可用，并且只对已经被放进来、或已被管理员激活的账号有效；其他人视为申请加入，等管理员处理。钉钉只有该应用所属组织的成员能登录；应用要把 `<公开地址>/auth/<渠道 id>/callback` 设为登录回调地址，并开通通讯录个人信息读权限和成员信息读权限。企业微信还没有渠道。
- 个人安装只有你一个人。在那里，邀请别人、放进发过消息的人、手动加人、同步通讯录都会被拒绝，并提示“这是你的个人安装，只有你一个人。要和别人协作，请加入或创建一个组织。”
  让人加入是在组织的安装上，由管理员管理。
- 飞书按 app 给同一个人发不同的 id，所以你在每个飞书 app、钉钉和每个浏览器里都是一个新 id。在个人安装里，设置 → 团队 → *为我的另一个账号生成绑定码*；从那个账号发送 `bind CODE`，或在浏览器里用它登录，那个账号就是你，机主。不会多出一个人。
- 个人安装出现之前的桌面安装里，你可能以每个 app 一个身份出现好几次。这时设置 → 团队会显示*查看这些是不是都是我*：列出每个身份的渠道、最近一次消息，以及合并会改变什么。只有每一个都是你本人时才合并；app 会重启，之后你就是持有所有账号的机主。你确认之前什么都不会变。
- 如果不全是你，选*这些不全是我*。什么都不会变，也不会移除任何人；之后设置 → 团队会提示这台电脑上的安装有多个人在用，多人协作请使用组织安装（组织跑在服务器上，由管理员管理）。要不要迁过去由你决定，不会替你迁移。
- 在钉钉里，只有设置了卡片模板，确认才会以卡片形式出现。没有模板时，你通过输入回复词来回答。
