# 渠道

人们怎样从飞书或钉钉找到你的 agent，以及谁能进来。

## 这是什么

**渠道**是聊天平台上的一个应用，比如一个飞书应用、一个钉钉应用，它通向你的 box。连接之后，那个聊天里的消息就是发给
agent 的消息，回复也回到同一个聊天里。那里的对话是**群**或私聊。同一个人在所有渠道上都是同一个人，所以在一个渠道里给出的确认，在另一个渠道里也算数。

群里的消息不一定是指令：群规则是*仅在被点名时回复*时，没有点名任何人的消息只作为上下文保留，不会得到回复。到设置 → 渠道查看这条规则。

## 怎么做

### 在 app 里

- **连接渠道：** 设置 → 渠道 → *添加渠道*，选择 `feishu` 或 `dingtalk`，再粘贴从该平台开发者后台拿到的应用凭据。
  凭据就位的渠道会马上连接，不用重启。
- **选择谁来回答：** 每个渠道一行，有一个默认 agent，也就是回答没有点名任何人的消息的那个 agent，还有一条群规则：
  *群：仅在被点名时回复*或*群：回复所有消息*。
- **让人进来：** 设置 → 团队 → *新建邀请码*。一个邀请码只能用一次，有效 15 分钟。在被放进来之前就发过消息的人，会在设置 → 渠道 →
  *等待加入*下面等着；点一下就能让他们进来。
- **连接服务：** 设置 → 渠道 → *连接器* → *连接*，接入一个外部服务（比如 Notion）给 agent 使用。

### 在聊天里

- `bind <code>`（或 `绑定 <码>`）：用邀请码加入。
- `@name <message>`：和某一个 agent 对话；其他消息都交给默认 agent。
- `/help`：列出这个聊天能识别的所有命令。
- `看板`、`团队`、`定时`：看板、agent，以及会自己运行的工作。

### 在命令行里

目前还没有渠道命令：渠道在设置 → 渠道里设置，凭据保存在 `~/.agentbox/config.json`。

## 在哪里看结果

- 设置 → 渠道：每个渠道，以及它是否已连接。
- 聊天本身：在飞书群里，回复是你那条消息下面的一个话题。
- 设置 → 团队：每个人和他的角色（观察者、操作者或管理员）。在你的个人安装（你电脑上的桌面 app）里，唯一的人就是你，机主。

## 限制

- 渠道的 id 只选一次；它会成为它放进来的每个人名字的一部分。显示名称和默认 agent 随时可以改。
- *添加渠道*提供飞书和钉钉。
- 个人安装只有你一个人。在那里，邀请别人、放进发过消息的人、手动加人、同步通讯录都会被拒绝，并提示“这是你的个人安装，只有你一个人。要和别人协作，请加入或创建一个组织。”
  让人加入是在组织的安装上，由管理员管理。用邀请码绑定你自己的手机仍然可以。
- 在钉钉里，只有设置了卡片模板，确认才会以卡片形式出现。没有模板时，你通过输入回复词来回答。
