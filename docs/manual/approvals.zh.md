# 确认

agent 自己能做什么、哪些事要先问你，以及你怎样回答。

## 这是什么

**确认**是你对一次请求的回答：agent 想做一件超出它 box 的事，比如向外部服务发帖，它会一直等到有人回答。
**工具权限**是事先设好的，按 agent、按工具设置：*已放行*、*问我*或*关闭*。**凭据检查**在工作开始前进行：
如果这项工作需要的密钥或连接器不在，就什么都不开始，并由一张卡片说明缺了什么。

“一直允许”不是一揽子同意：它只放行那一个完全相同的操作，只对那个 agent 有效，直到你撤销为止。到设置 → 我的 →
*长期确认*查看。

## 怎么做

### 在 app 里

- **回答请求：** 聊天里的卡片写着这是一次*确认*、哪个 agent 在等、要做什么操作，以及 agent 用自己的话怎么说明它。
  按*允许一次*、*本次会话*、*一直允许*或*拒绝*。
- **设定 agent 能用什么：** *配置* → *工具*。点击一个工具，可在 允许 → 先问我 → 关闭 之间切换；*关闭*的工具根本不提供给
  agent。上面一行一次设定整组工具（*桌面*、*网页*、*代码*、*团队*、*其他*）为*放行*、*问我*或*关闭*。虚线标签表示你的组织已经要求先确认；
  悬停可以看到来源。
- **撤销“一直允许”：** 设置 → 我的 → *长期确认* → *撤销*。下一次相同的操作会重新询问。
- **补上缺少的东西：** “要让 <agent> 开始 <task>”卡片逐项列出缺少的密钥或连接器，并附有按钮，通往设置 → 团队（密钥）或设置 →
  渠道（连接器）。补齐之后，工作会自己开始。

### 在聊天里

- 整条消息回复 `允许`（一次）、`一直允许`（一直）、`本次会话`（本次会话）或 `拒绝`（拒绝）。英文也可以：`allow`、
  `always`、`session`、`deny`。
- 在飞书里，卡片有三个按钮：允许这一次、一直允许、拒绝。
- 如果工作开始前缺少东西，agent 会回复“<agent> 开始前需要：”，每项一行。补齐之后，任务会自己开始；你不用再发一遍。

### 在命令行里

- 整个安装的长期规则是 `~/.agentbox/rules` 里的 Markdown 文件，每条规则一个文件，写明它匹配什么，以及 `allow`、
  `ask` 或 `deny`。[规则语法](reference-rules.zh.md)列出了每个字段。
- `AGENTBOX_TIER_GATE=enforce` 让 LumenBox 在每个超出 box 的操作前都先询问。默认只把这些操作记录下来。

## 在哪里看结果

- 聊天里每个工具步骤都带一个标记：`allowed`、`asked you`、`waiting for you` 或 `refused`。点击它，可以看到是哪条规则或哪项设置做的决定。
- 设置 → 我的：你的长期确认，以及*本会先问的操作（最近 7 天）*，也就是如果强制执行确认，LumenBox 会问你的那些操作。
- 任务标签页：因缺少凭据而被挂起的任务显示“<task> 正在等待：开始前需要”。

## 限制

- 请求会一直等到有人回答，最长 24 小时。过期的请求按拒绝处理，所以迟到的点击不会让它运行。
- *本次会话*持续到 app 重启为止。
- agent 上的*已放行*永远解除不了你的组织设下的 *ask* 或 *deny*。
- 有些只和你对话的工具只能是已放行或关闭，不能设为*问我*。
