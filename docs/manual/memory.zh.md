# 记忆

本页讲 agent 在对话之间记住了什么，以及你怎么查看、更正或删除这些内容。

## 这是什么

**记忆**是 agent 记住的事实：每条一行，并注明来源。每个 agent 有自己的记忆。一个团队还有一份共享记忆，box 里的每个 agent 都能读。agent 用 `RememberFact` 工具保存一条事实，用 `Recall` 查找，用 `Forget` 删除一条。`Recall` 既按字面查找，也按内容主题查找，所以搜 "deploy" 也能找到一条讲发版的记录。

开启审核时，团队事实在同意之前不会共享：在 设置 → 团队 → 团队记忆 里勾选 *先审后发* 后，写入团队记忆的内容要等管理员确认。请到 团队记忆 下面的列表里查看。

## 怎么做

### 在 app 里

- **查看：** 设置 → 记忆 按 box 列出各个 agent，并显示每个 agent 记了多少行。打开一个 agent 就能读它的每一行；团队的行标有 `· team`（界面显示为 `· 团队`）。
- **更正一行：** 在这一行上点 *编辑*。**删除一行：** 点 *撤回*。要删除从同一来源学到的全部内容，点 *撤回 <来源>*。
- **审核团队写入：** 设置 → 团队 → 团队记忆。勾选 *先审后发*，然后对每条等待中的写入点 *同意* 或 *拒绝*。
- **agent 对你的了解：** 设置 → 我的 → 关于我。你自己写的行优先于 agent 学到的内容。

### 在聊天里

没有记忆命令。直接说要记住什么，例如“记住：周报发到产品群”，agent 就会保存。要它忘掉某件事也这样说；它会先请你确认。

### 在命令行里

没有记忆命令。`agentbox backup` 会把记忆连同 `~/.agentbox` 的其余内容一起复制；记忆就存放在你电脑上的这个目录里。

## 在哪里看结果

- 设置 → 记忆：每一行、它的来源，以及已撤回的行。
- 下一轮：改动会在 agent 的下一轮生效。
- 在 box 里，*文件* 标签页下的 `memory/<agent id>/profile.md`：同一份记忆的只读副本。

## 限制

- 一条事实少于 500 个字符。
- `profile.md` 由 LumenBox 重写。在那里的修改会丢失；请改用 设置 → 记忆。
- 团队记忆审核默认关闭，直到管理员勾选 *先审后发*。被拒绝的写入永远不会共享。
- 按含义查找用的是一份固定的近义词表，不是模型。措辞差别很大的事实仍可能找不到。
