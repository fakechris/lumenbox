# LumenBox 0.3.14: pause an agent, and hear when one reaches for credentials

## What is new

**Pause an agent until you resume it.** Settings → Team → Agents has *Pause* next to each
agent. A paused agent starts no turns: what people and teammates send it waits in its queue,
and a restart does not lift the pause. Pausing also ends the turn in flight and stops the
agent's running background jobs. *Resume* hands it the queued messages with a note saying who
paused it and for how long. The sidebar marks a paused agent. *Stop* still ends only the
current turn.

**An agent hunting for credentials is refused, and you hear about it.** Some commands try to
reach this Mac's credentials or get around the box's boundary:
- reading another process's environment;
- decrypting the box browser's cookies;
- claiming an identity with the gateway's headers;
- calling this Mac's LumenBox from inside the box;
- searching files for token-shaped strings.

LumenBox refuses these before they run and tells the agent why. Admins get a message in their
chats, and the attempt shows on the "needs you" list. Three attempts in an hour pause the agent
until a person resumes it.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.14-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.14.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.
