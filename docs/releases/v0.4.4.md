# LumenBox 0.4.4: finished work no longer waits for your Accept

## What is new

**A request ends when its result is delivered.**
Every request you made used to end in *Finished, waiting for you to look*, with Accept and Request changes. That held even for an answer you had read in the chat weeks earlier. Now a request ends when its result is delivered. If the result is wrong, say so in the conversation and the agent reopens it.

**You are asked only when your word changes something.** A result still waits for you when:
- other work waits on it, and would start on something nobody looked at;
- files were handed over;
- you asked to see it first, wrote acceptance criteria, or named a person to review it;
- it was handed back unfinished (out of budget, or stuck);
- a check could not decide;
- somebody, you included, commented on it after it was delivered.

The card and the inbox say which of these applies, for example *确认后，等着它的 1 件事会开始*. The buttons say what they do: *确认，结束这件事* and *打回修改*.

**A result nobody answered for 7 days ends on its own,** unless other work waits on it. Set `AGENTBOX_REVIEW_LAPSE_DAYS` to change the 7.

Neither ending counts as your acceptance. The record says that no person accepted it.

A request asked in a conversation older than the loaded list is named by its first line, or by its chat, for example *飞书里的一个对话*. It no longer reads *another conversation*.

## Upgrading

No stored data changes format. On first start, results that nothing needs your word on end at once. So do results that have waited more than 7 days. Each one says so in its history.

## macOS downloads

- Apple Silicon: `LumenBox-0.4.4-arm64.dmg` or `LumenBox-0.4.4-arm64-mac.zip`
- Intel: `LumenBox-0.4.4.dmg` or `LumenBox-0.4.4-mac.zip`

These builds are **not Apple notarized**, so macOS may block the first opening. Either right-click LumenBox and choose *Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

`SHA256SUMS` identifies the exact published files.
