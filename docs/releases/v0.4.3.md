# LumenBox 0.4.3: an agent has one conversation

## What is new

**An agent's chat topics sit in its conversation.**
An agent that works in Feishu, DingTalk or Telegram topics used to show them as cards at the foot of its main conversation. Each card read *From Feishu* above a line of unrendered markdown. Opening one swapped the whole page for that topic, and the way back was a drop-down at the top.

Now an agent has one conversation:
- Each topic stands in it at the time of the agent's last answer. It shows the question that opened the topic, marked with the chat's icon, and the last answer rendered as written.
- *Show the whole exchange* opens the topic in place, and *Fold it* closes it. You never leave the agent.
- A result asked for in a topic stands under that topic.
- While the agent answers in a topic, the topic says so. It refreshes when the answer is done.
- A link to a topic, or *Asked in … — go there* in the work panel, opens the agent with that topic open.
- Search and export cover the topics too.
- The conversation drop-down is gone. What you type below always goes to the agent on the page.
- A message that arrived through a chat carries the chat's icon instead of the words *From Feishu*.

Replying into a Feishu topic from the page is not part of this release.

## Upgrading

No stored data changes format.

## macOS downloads

- Apple Silicon: `LumenBox-0.4.3-arm64.dmg` or `LumenBox-0.4.3-arm64-mac.zip`
- Intel: `LumenBox-0.4.3.dmg` or `LumenBox-0.4.3-mac.zip`

These builds are **not Apple notarized**, so macOS may block the first opening. Either right-click LumenBox and choose *Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

`SHA256SUMS` identifies the exact published files.
