# LumenBox 0.3.13: a box that keeps itself up, and settings that look like one app

## What is new

**A box stopped from outside comes back by itself.** If something other than you stops the box
(a `docker stop`, a Docker engine restart), LumenBox notices within a minute and tells admins in
their chats. It stops the turns that can only fail against a missing box, starts the box again,
and lets those agents go on once it is back. A box you stopped with `agentbox box down` stays
stopped.

**Updating the box no longer waits on work that cannot move.**
- *Apply update* waits only for this box's work in progress. If the box is stopped or does not
  answer, there is nothing to interrupt, so the update goes ahead.
- *Update now…* updates without waiting, after saying what it interrupts.

**Settings look like one app.**
- Dropdowns have one look, with room beside the arrow.
- Spacing and type sizes follow one scale.
- The Supervision, Boxes and Jev sections use the same components as the rest of the page.

**Fixes**

- The supervisor wizard's "Set up the supervisor step by step" button hides while the wizard
  is open. Before, it sat above the wizard looking like its title, and clicking it did nothing.
- Deleting an agent in the middle of a turn is refused, as it was always meant to be.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.13-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.13.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

## The box image

`fakechris/lumenbox:0.3.13` (linux/arm64), with the same engines as 0.3.12: opencode 1.18.25,
Claude Code 2.1.250, pi 0.85.1 and mcode 0.6.12. To update the box, open Settings → Boxes and
choose **Apply update**.
