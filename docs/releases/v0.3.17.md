# LumenBox 0.3.17: the first summary of a very long conversation fits

## What is new

**A long conversation's first summary no longer tries to send all of it.** When an agent had a
very long history that had never been summarised, its first summary used to hand the whole
history to the model. That request could be larger than any model accepts, so the summary failed,
and building it cost several hundred megabytes of memory. Now that summary gets the most recent
part that fits, with a line saying how many earlier entries were left out. Normal summaries are
unchanged.

In a load test with five agents, each holding a 30 MB conversation that had never been
summarised, the app's memory peak fell from about 690 MB to about 240 MB.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.17-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.17.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

`fakechris/lumenbox:0.3.17` (linux/arm64), with the same engines as 0.3.16: opencode 1.18.25,
