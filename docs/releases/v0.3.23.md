# LumenBox 0.3.23: the "Needs you" strip stays small

## What is fixed

**"Needs you" no longer fills the sidebar.** In 0.3.22 it listed every task waiting for review —
hundreds, on a busy board — and pushed the agent list out of sight; its *Open* button did nothing
on the chat view. It now shows only what blocks an agent (a consent, a question, a pause, a
message that could not be delivered), at most five with "+N more on the board", and folds the
tasks waiting for review into one line that opens the board. *Open* switches to the board.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.23-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.23.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

## The box image

`fakechris/lumenbox:0.3.23` (linux/arm64) is the same image as 0.3.19 through 0.3.22. Nothing in
the box changed.
