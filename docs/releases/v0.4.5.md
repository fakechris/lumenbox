# LumenBox 0.4.5: a box update no longer copies your files by default

## What is new

**A box update backs up the box's files only when you ask.**
An update replaces the box's container and leaves its files where they are. Settings → Boxes still ticked *Back up the work folder first* by default. So every update spent a couple of minutes packing the work and config folders, and left about 1 GB in `~/.agentbox/backups`.

Now the box is unticked unless you tick it. A line beside it says what a backup costs. A tick made before *Update now* survives its confirmation. The classic page and the command line already worked this way, and all three now read the same default.

## Upgrading

No stored data changes format. Earlier backups in `~/.agentbox/backups` are not removed. Delete the ones you no longer need.

## macOS downloads

- Apple Silicon: `LumenBox-0.4.5-arm64.dmg` or `LumenBox-0.4.5-arm64-mac.zip`
- Intel: `LumenBox-0.4.5.dmg` or `LumenBox-0.4.5-mac.zip`

These builds are **not Apple notarized**, so macOS may block the first opening. Either right-click LumenBox and choose *Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

`SHA256SUMS` identifies the exact published files.
