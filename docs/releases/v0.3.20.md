# LumenBox 0.3.20: the spend line no longer ends ordinary turns

## What is fixed

**Agents' turns are no longer cut short after five or six rounds.** In 0.3.19, a model with no
configured price was held to a token line that counted re-read context at full weight. A model
that re-reads ~90k tokens of cached context each round crossed the 500k per-wake line in about
six rounds, so the turn ended with "handed back" while it was still working. Re-read (cached)
tokens now count at a tenth, which is what providers charge for them, and the defaults are 2M
per wake and 30M per day. You can still change each agent's lines in Settings → Team → Agents.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.20-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.20.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

## The box image

`fakechris/lumenbox:0.3.20` (linux/arm64) is the same image as 0.3.19, with the same engines:
opencode 1.18.25, Claude Code 2.1.250, pi 0.85.1 and mcode 0.6.12. Nothing in the box changed.
