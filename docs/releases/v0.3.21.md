# LumenBox 0.3.21: long chats open instantly

## What is fixed

**Opening a long conversation no longer freezes the window.** A chat now opens on its newest
400 entries, with one line at the top saying how many earlier ones are not shown. Before, the
page drew every entry at once: a chat with about 14,000 entries froze the window for minutes,
used more than a gigabyte of memory, and buttons clicked in the meantime (such as refusing an
approval) did nothing. The earlier entries are still on the record, and agents still reach them
with their History tool.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.21-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.21.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

## The box image

`fakechris/lumenbox:0.3.21` (linux/arm64) is the same image as 0.3.19 and 0.3.20, with the same
engines: opencode 1.18.25, Claude Code 2.1.250, pi 0.85.1 and mcode 0.6.12. Nothing in the box
changed.
