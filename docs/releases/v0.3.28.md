# LumenBox 0.3.28: a rebuilt box image

## What is new

**The box image is rebuilt on the current Debian base** with the updated document libraries,
the same four engines as before (opencode 1.18.25, claude 2.1.250, pi 0.85.1, mcode 0.6.12),
and the host's updated dependencies. No behaviour changes in the app beyond 0.3.27; the box
will offer *Apply update* once the app runs.

**Also on this main since 0.3.27:** each agent's tools can be set to allow, ask me, or off, and
the gate's verdict shows on every step; a task can mark a file as its deliverable, kept and
downloadable; the reference pages are generated from the registries and the suite fails when
they drift.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.28-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.28.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.
