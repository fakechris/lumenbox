# LumenBox 0.4.0: the rebuilt page, and one conversation wherever you read it

## What is new

**The page is rebuilt around talking to a named agent on a computer.** The agent list is grouped
by computer. An agent's unfinished work is pinned in the conversation it was asked in, what needs
you is one click away, and detail opens in place; raw steps, usage and identifiers are under a
separate Diagnostics tab. Every Settings pane is here. The earlier page is still there: *Back to
the classic view* at the foot of the side column, and the choice is remembered. (The rebuilt page
first went out in 0.3.32; this release is the one it is finished in.)

**A result tells you what it is before it asks you to decide.** A card for finished work says where
the request came from (this page, Feishu, DingTalk, or an agent of its own accord) and shows what
was reported about it. *Accept* closes it; *Request changes* takes your note on the card and sends
the work back; *Details* opens the panel. The card appears in the conversation the work was asked
in, and from anywhere else a line tells you how many are waiting there and takes you to them.

**What the host writes is not drawn as something you said.** Context digests, audit requests and
job notices used to appear in your bubble in older conversations. They are host context now,
whatever the old record stamped them.

**A chat and its conversation in LumenBox say the same thing.** If you talk to an agent through
Feishu, DingTalk or Telegram:

- The line an agent says as it starts to work, which the chat always received, is now on the page
  too.
- An answer that LumenBox sent back for a check (quotation marks, files about to be posted, a
  message of yours that arrived meanwhile) is no longer replaced by the agent's note about the
  fix. You get the answer, then the note — in the chat and on the page.
- What the chat receives that is not the agent speaking — the acknowledgement, a progress or
  question card, a file, a notice — appears on the page as a quiet row, *sent to the chat*, at its
  time. This starts with this release: earlier conversations have no such rows.
- Messages you sent in a chat are no longer marked *unknown source* on the page.
- A chat with several topics is one entry in the conversation picker, with its topics under it.

**An unread count leads somewhere.** The number on an agent's row is over all its conversations.
The picker marks the ones holding it, the open conversation has a line to each, and looking clears
it at once.

**Long requests carry on.** An ordinary request that outgrows one turn is continued by the host
until it is answered, under a ceiling you set for the installation (Settings; default 30
continuations or 12 active hours). The retry allowance is counted over 24 hours, and a message
from another agent no longer waits behind your unfinished work.

## Upgrading

No stored data changes format. Switching between the two pages changes nothing but the page.
LumenBox starts keeping a record of what it sends to chats (`sent/` in its data folder); nothing
you already have is rewritten.

## macOS downloads

- Apple Silicon: `LumenBox-0.4.0-arm64.dmg` or `LumenBox-0.4.0-arm64-mac.zip`
- Intel: `LumenBox-0.4.0.dmg` or `LumenBox-0.4.0-mac.zip`

These builds are **not Apple notarized**. macOS may block the first opening: right-click LumenBox
and choose *Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.
`SHA256SUMS` identifies the exact published files.

## Box image

`fakechris/lumenbox:0.4.0` — linux/arm64. The app offers *Apply update* for the box once it runs.
