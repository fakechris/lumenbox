# LumenBox 0.3.16: less memory for long conversations, and a plan that stays out of the way

## What is new

**LumenBox uses far less memory when agents have long histories.** In a load test with five
agents, each holding a 30 MB conversation and working through background jobs, the app's average
memory fell from about 540 MB to about 230 MB, and its process memory peak from 1.6 GB to about
830 MB. When the conversations have been summarised before, as long-lived ones have, its memory
peaks under 250 MB.
- An agent's conversation is read from disk once and then only what was added. Before, each
  turn read and parsed the whole file about five times.
- Saving memories before a conversation is summarised stays within its 12,000-character
  limit. Before, a long conversation could build an extraction request of several megabytes,
  send it to the model, and keep copies of it.
- A turn no longer does work over the whole conversation when it only needs the latest part.

**A long plan no longer covers the conversation.** The plan above the chat stops at about a
third of the window and scrolls inside. When more than three steps are done, they fold into one
line, "✓ 21 done · show", which you can click to see them again. Steps in progress or still to
do always show.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.16-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.16.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

## The box image

`fakechris/lumenbox:0.3.16` (linux/arm64), with the same engines as 0.3.15: opencode 1.18.25,
Claude Code 2.1.250, pi 0.85.1 and mcode 0.6.12. Nothing inside the box changed in this
release. To move the box to the new tag, open Settings → Boxes and choose **Apply update**.
