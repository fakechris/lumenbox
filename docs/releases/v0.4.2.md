# LumenBox 0.4.2: work with nobody behind it is a proposal, and the chat and the page read one record

## What is new

**Work nobody asked for proposes; it doesn't start.**
Between 2 and 10 November, the agents on one installation made 1,633 cards for themselves and each other, while a person made 39. Nothing was delivered.

- A turn that only a teammate or the task board woke may still put work on the board. That work is now a proposal, which a person commits. Nobody is told to start on it.
- Work made under your request keeps its standing as it moves:
  - when it is handed to another agent;
  - when it waits on a blocker;
  - when the board wakes someone for it.
- Routines you set still count as your requests.

**What was spent with no request behind it is marked.**
Usage written in such turns is marked. The spend report shows that share beside the total, for a day or for everything on file. Nothing is paused because of it.

**One rough choice for long work.**
*Settings → Long work* is now *Lean / Standard / Open*, and the numbers behind it are folded away.
- At the 2nd, 4th, 8th and 16th continuation, the agent is shown what it has spent so far and decides for itself:
  - go on;
  - deliver what it has and say what is left out;
  - stop and say why.
- You are not asked.

**A conversation is drawn from a record, not a guess.**
Each message an agent hears is now recorded with who sent it. Each opening line and reply it gives is recorded too. The chat reply and the page's bubbles both read that record. What Feishu, DingTalk or Telegram received and what the page shows can no longer diverge.
- A request that came through a chat says which one.
- A turn a routine opened shows the routine as its request.
- Conversations from before 0.4.2 keep the older reading.

**An agent's other conversations are one block.**
The scattered lines like *"1 more waiting for you, in another conversation"* are replaced by *Other conversations*.
- One row per conversation: the question that opened it, the agent's last reply, what is waiting there, and when.
- Newest first; a row opens the conversation.
- For an agent that works mostly in Feishu topics, this is where that work shows.

**Poppy (Personal Agent Protocol): built, off by default.**
Agents can talk with companies that publish `/.well-known/poppy.json`:
- discover what a company offers;
- send it signed requests;
- talk with its own agent;
- use UCP commerce over MCP.

When a company asks for approval of an action, it reaches you as a consent card that shows the company and the exact terms. Only your approval is sent back.

It needs `AGENTBOX_POPPY=1` and a public `https://` address in `AGENTBOX_PUBLIC_URL`, so it does nothing on a typical desktop install. Sign-in isn't available yet. See `docs/poppy.md`.

## Upgrading

No stored data changes format. New records start with this version:
- `heard/` — who said what;
- the usage mark.

Older conversations and usage stay as they were.

## macOS downloads

- Apple Silicon: `LumenBox-0.4.2-arm64.dmg` or `LumenBox-0.4.2-arm64-mac.zip`
- Intel: `LumenBox-0.4.2.dmg` or `LumenBox-0.4.2-mac.zip`

These builds are **not Apple notarized**, so macOS may block the first opening. Either right-click LumenBox and choose *Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

`SHA256SUMS` identifies the exact published files.
