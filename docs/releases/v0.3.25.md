# LumenBox 0.3.25: how far an agent may go alone, and what it found

## What is new

**Every task carries an autonomy level, L1 to L5.** L1 only observes and reports; L2 proposes
but changes nothing; L3 acts within the box; L4 acts outward (sending, publishing) after a
consent; L5 is a standing contract the agent pursues on its own. The level is inferred when a
task is created, with the rule written into its history, and you can change it from the board's
L1–L5 selector. The gate reads it: a task below L3 cannot change anything, and at L3 and L4 an
outward action asks first.

**A decision put to you carries the agent's case, labelled.** A consent card now shows why the
agent wants the action, in its own words and marked as unchecked, apart from the action itself;
a question shows which answer the agent leans to. The same text reaches Feishu cards.

**Agents can sense and propose.** A sensing routine looks around on a schedule and writes what it
finds as proposals on the board: a to-do, a problem, an opportunity, a decision. Each names its
source and evidence; the same finding is never proposed twice, and a dismissed one stays
dismissed. Nothing is work until you commit it. The Tasks page has an *Inbox only* toggle.

**The sidebar strip no longer hides the agents.** Tasks waiting for your review fold into one
line that opens the board; the strip shows at most three one-line decisions.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.25-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.25.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.
