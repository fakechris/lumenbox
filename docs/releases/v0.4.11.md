# LumenBox 0.4.11: local port-forward bootstrap unlock and channel setup

An operator reaching an organisation installation over a local port-forward can now unlock operator settings without hitting a sign-in loop, set the OAuth callback base URL, and configure DingTalk or Feishu credentials directly in `Settings → Channels`.

## What changed

**Local port-forward bootstrap and channel setup**
- At the `local` exposure level (such as `kubectl port-forward` or SSH port forwarding), `/bootstrap` and the `401` sign-in recovery page now provide an inline operator credential unlock form alongside a copyable command to read `/state/ui-token` (or the local `ui-token` file), opening `Settings → Channels` directly instead of bouncing back to `/bootstrap`. Non-local (`private` and `public`) installations continue to refuse operator token browser sign-in (`403 token-not-here`).
- `Settings → Channels` adds `Set credentials` / `Update credentials` actions on existing DingTalk and Feishu rows, displays the `/auth/<id>/callback` OAuth redirect URL hint for both DingTalk and Feishu, and rejects partial single-field credential submissions cleanly.
- `Settings → Channels` adds an editable OAuth callback base URL (`AGENTBOX_PUBLIC_URL`) card with `Use current origin` for local tunnels, locks the field when set from the process environment, and refuses clearing it when non-local exposure requires HTTPS at startup.

## Upgrading

Data from 0.4.10 loads unchanged. On Kubernetes (`organisation.yaml` or `control-plane.yaml`), update the Deployment container `image` (and `AGENTBOX_IMAGE` on `control-plane.yaml`) to `fakechris/lumenbox:0.4.11`.

## macOS downloads

- Apple Silicon: `LumenBox-0.4.11-arm64.dmg` or `LumenBox-0.4.11-arm64-mac.zip`
- Intel: `LumenBox-0.4.11.dmg` or `LumenBox-0.4.11-mac.zip`

These builds are **not Apple notarized**, so macOS may block the first opening. Either right-click LumenBox and choose *Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

`SHA256SUMS` identifies the exact published files.

## Box image

`fakechris/lumenbox:0.4.11` — linux/amd64 and linux/arm64. Once the app is running, it offers *Apply update* for the box.
