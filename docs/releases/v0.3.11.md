# LumenBox 0.3.11: update the box from the app

## What is new

**The box updates like an app.** When a new LumenBox expects a newer box image, Settings → Boxes
says an update is available and offers **Apply update**. Admins also get a message and an item
on their "needs you" list. Replying `upgrade` in a chat does the same.

- It waits for work in progress to finish, then recreates the box on the new image.
- What agents made (`work`) and your browser logins (`.config`) stay: they are on volumes,
  not in the box. Anything written elsewhere in the box does not.
- The new box is checked by driving its browser. If it does not work, the box goes back to the
  image it had.
- No backup by default. A checkbox, or `agentbox box up --recreate --backup`, asks for one.
- **Reset the box…** is separate: it starts an empty box and deletes what agents made and every
  login, so it asks for the box's name.
- The check before an update lists only files the box wrote outside the two volumes, never the
  image's own files.

**Fixes**

- The server no longer stops when the system writes a note for a task assignee that is not an
  agent. On 0.3.10 this could restart LumenBox several times a day.
- The task board refuses an assignee or reviewer that is not an agent on the team.
- In the desktop app, correcting a memory line, choosing who a box is for, renaming a team and
  snoozing a "needs you" item work again. They used a browser dialog the app does not have; they
  now ask in the page.

## Install on macOS

Download the disk image for your Mac, open it, and drag LumenBox to Applications.

- `LumenBox-0.3.11-arm64.dmg`: Apple Silicon
- `LumenBox-0.3.11.dmg`: Intel

The apps are signed but **not notarized**. The first time, right-click LumenBox and choose
*Open*, or run `xattr -dr com.apple.quarantine /Applications/LumenBox.app`.

## The box image

`fakechris/lumenbox:0.3.11` (linux/arm64) carries opencode 1.18.25, Claude Code 2.1.250, pi
0.85.1 and mcode 0.6.12, the same engines as 0.3.10. After installing the app, open
Settings → Boxes and press **Apply update**.
